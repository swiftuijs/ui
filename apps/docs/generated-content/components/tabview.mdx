## Usage and limitations

- Provide items with `label` and `content`; optional `icon`, `badge`, and `disabled` customize each tab.
- Give items stable `value` identifiers. Controlled: `selection`/`onSelectionChange`; uncontrolled: `defaultSelection`. Avoid depending on changing item order.
- Tab bar position is `bottom` by default or `top`.
- Uses tablist/tab/tabpanel semantics. Arrow keys, Home and End move between enabled tabs; use short, descriptive labels and focused panel content.
