Start with [Button](/docs/components/button), [TextField](/docs/components/textfield), [VStack](/docs/components/vstack), or [Sheet](/docs/components/sheet). Each reference includes a live example, code, requirements and the complete API.

Use search to find a component by name. Check the [capability matrix](/docs/concepts/capability-matrix/) for web adaptations and experimental features.

## All components

- [ActivityIndicator](/docs/components/activityindicator): Show that an asynchronous task is in progress.
- [Alert](/docs/components/alert): Present a short message that requires attention or a decision.
- [AllowsHitTesting](/docs/components/allowshittesting): AllowsHitTesting adapts SwiftUI's `allowsHitTesting(_:)` modifier into an explicit interaction wrapper for web overlays and disabled hit regions.
- [AngularGradient](/docs/components/angulargradient): AngularGradient sweeps color stops around a center point.
- [AspectRatio](/docs/components/aspectratio): Constrains content to a target ratio, aligned with SwiftUI's aspectRatio modifier.
- [AsyncImage](/docs/components/asyncimage): AsyncImage loads remote images and exposes simple loading and failure phases, aligned with SwiftUI's `AsyncImage` mental model.
- [Badge](/docs/components/badge): Display a short count or status beside related content.
- [Button](/docs/components/button): A native HTML button with SwiftUI-inspired styling. Pass ordinary button props and an `onClick` handler; use `type="submit"` inside a form.
- [Canvas](/docs/components/canvas): Canvas exposes the browser's drawing surface with a SwiftUI-style dedicated component wrapper.
- [Card](/docs/components/card): Visually group related content in an elevated container.
- [Chart](/docs/components/chart): Chart presents numeric series as either bar or line marks.
- [Color](/docs/components/color): Render a CSS color swatch or background.
- [ColorPicker](/docs/components/colorpicker): ColorPicker wraps the native color input while keeping SwiftUI-style label and value semantics.
- [ConfirmationDialog](/docs/components/confirmationdialog): ConfirmationDialog presents a stack of actions that asks the user to confirm an intent. It aligns with SwiftUI's `confirmationDialog` mental model while using web-native dialog semantics.
- [ContainerBackground](/docs/components/containerbackground): ContainerBackground adapts SwiftUI's `containerBackground(_:for:)` modifier into an explicit surface wrapper for navigation and grouped content areas.
- [ContainerRelativeFrame](/docs/components/containerrelativeframe): Sizes content relative to its container using SwiftUI-style count, span, and spacing semantics.
- [ContentMargins](/docs/components/contentmargins): Adds configurable content insets using SwiftUI-style edge semantics.
- [ContentTransition](/docs/components/contenttransition): ContentTransition adapts SwiftUI's content-transition modifiers into an explicit wrapper that annotates changing content on the web.
- [ContentUnavailableView](/docs/components/contentunavailableview): ContentUnavailableView presents polished empty states for missing data, search misses, and first-run experiences.
- [ContextMenu](/docs/components/contextmenu): ContextMenu presents a menu of actions from a context interaction. On the web this maps to the native right-click gesture while preserving SwiftUI's contextual action model.
- [ControlGroup](/docs/components/controlgroup): ControlGroup clusters related actions under a shared label. The component keeps SwiftUI's grouped-control mental model while using standard web grouping semantics.
- [DatePicker](/docs/components/datepicker): Select a date or time using the browser’s native input.
- [DefaultScrollAnchor](/docs/components/defaultscrollanchor): DefaultScrollAnchor adapts SwiftUI's `defaultScrollAnchor` modifier into an explicit wrapper.
- [DisclosureGroup](/docs/components/disclosuregroup): Show or hide related content behind an expandable label.
- [Divider](/docs/components/divider): Separate adjacent content with a decorative line.
- [FileImporter](/docs/components/fileimporter): FileImporter presents a button-backed file picker and forwards selected files to your app.
- [ForEach](/docs/components/foreach): Render an array with a stable key and a render function.
- [Form](/docs/components/form): Group input controls in a native HTML form.
- [Gauge](/docs/components/gauge): Gauge shows a current value within a bounded range, matching SwiftUI's summary-style meter while keeping standard `progressbar` semantics.
- [GeometryReader](/docs/components/geometryreader): Read a container’s size and viewport position through a render function.
- [Glass](/docs/components/glass): Add an optional glass material to a custom control surface.
- [Grid](/docs/components/grid): Grid arranges content in explicit rows and columns, following SwiftUI's non-lazy grid model.
- [GridRow](/docs/components/gridrow): GridRow defines a single row inside `Grid`.
- [Group](/docs/components/group): Group children in an unstyled HTML container.
- [GroupBox](/docs/components/groupbox): Visually group related content with an optional label.
- [HelpLink](/docs/components/helplink): HelpLink presents a dedicated support affordance aligned with SwiftUI's `HelpLink`, adapted to the web as an anchor.
- [HoverEffect](/docs/components/hovereffect): HoverEffect adapts SwiftUI's hover feedback modifiers into explicit pointer-oriented wrappers for the web.
- [HSplitView](/docs/components/hsplitview): HSplitView lays out multiple panes side by side, adapting SwiftUI's horizontal split container model to a proportional flex layout on the web.
- [HStack](/docs/components/hstack): Arrange children in a horizontal row with configurable spacing and vertical alignment.
- [Image](/docs/components/image): Display an image using a native HTML `img` element.
- [Inspector](/docs/components/inspector): Inspector presents supplemental controls or contextual details beside primary content.
- [KeyframeAnimator](/docs/components/keyframeanimator): KeyframeAnimator steps through explicit frame values over time, exposing each frame to a render function.
- [Label](/docs/components/label): Combine a title with an optional icon.
- [LabeledContent](/docs/components/labeledcontent): LabeledContent presents a label and related value using the same compact summary pattern as SwiftUI.
- [LazyHGrid](/docs/components/lazyhgrid): A measured, virtualized horizontal grid. Only the viewport and a small overscan window mount, including when scrolling the page.
- [LazyHStack](/docs/components/lazyhstack): A measured, virtualized horizontal stack. Only the viewport and a small overscan window mount, including when scrolling the page.
- [LazyVGrid](/docs/components/lazyvgrid): A measured, virtualized vertical grid. Only the viewport and a small overscan window mount, including when scrolling the page.
- [LazyVStack](/docs/components/lazyvstack): A measured, virtualized vertical stack. Only the viewport and a small overscan window mount, including when scrolling the page.
- [LinearGradient](/docs/components/lineargradient): LinearGradient fills a view using color stops distributed along a line.
- [Link](/docs/components/link): Open a URL through a native anchor.
- [List](/docs/components/list): Group rows and sections in a list-style container.
- [MapView](/docs/components/map): MapView embeds a coordinate-based map surface using a web map provider while keeping SwiftUI's location-focused mental model.
- [MatchedGeometryEffect](/docs/components/matchedgeometryeffect): MatchedGeometryEffect adapts SwiftUI's `matchedGeometryEffect` modifier into explicit shared metadata on the web.
- [Menu](/docs/components/menu): Open a positioned menu of actions from a trigger.
- [MeshGradient](/docs/components/meshgradient): MeshGradient adapts SwiftUI's mesh gradient concept into a layered CSS radial-gradient surface for the web.
- [MultiDatePicker](/docs/components/multidatepicker): MultiDatePicker adapts SwiftUI's multi-date selection model to the web by combining a native date input with an ordered list of selected dates.
- [NavigationBar](/docs/components/navigationbar): Display a title, optional back button and page actions.
- [NavigationLink](/docs/components/navigationlink): Navigate to a React page inside `NavigationStack`, open a URL, or dismiss the current page.
- [NavigationSplitView](/docs/components/navigationsplitview): NavigationSplitView presents sidebar, optional content, and detail columns with a compact fallback mode.
- [NavigationStack](/docs/components/navigationstack): Manage an in-memory stack of React pages with forward and back navigation.
- [OutlineGroup](/docs/components/outlinegroup): OutlineGroup renders hierarchical content as an expandable outline, aligned with SwiftUI's tree presentation.
- [StandardPage](/docs/components/page/standard-page/standardpage): Give a navigation page a title, toolbar and content area.
- [PasteButton](/docs/components/pastebutton): PasteButton reads plain text from the clipboard and forwards it to your app, aligned with SwiftUI's clipboard action model.
- [PhaseAnimator](/docs/components/phaseanimator): PhaseAnimator sequences a finite set of named phases and re-renders your content with the current phase value.
- [PhotosPicker](/docs/components/photospicker): PhotosPicker opens an image-only asset chooser and forwards selected files, keeping SwiftUI's media selection intent while relying on the browser's native file picker.
- [Picker](/docs/components/picker): Choose one value from a native select control.
- [Popover](/docs/components/popover): Popover presents lightweight content anchored to another control. It aligns with SwiftUI's `popover` presentation while keeping web-friendly dialog semantics.
- [PresentationBackground](/docs/components/presentationbackground): PresentationBackground adapts SwiftUI's `presentationBackground` modifier into an explicit surface wrapper.
- [PresentationCompactAdaptation](/docs/components/presentationcompactadaptation): PresentationCompactAdaptation adapts SwiftUI's `presentationCompactAdaptation` modifier into an explicit wrapper.
- [PresentationCornerRadius](/docs/components/presentationcornerradius): PresentationCornerRadius adapts SwiftUI's `presentationCornerRadius` modifier into an explicit wrapper.
- [PresentationDragIndicator](/docs/components/presentationdragindicator): PresentationDragIndicator adapts SwiftUI's `presentationDragIndicator` modifier into an explicit wrapper.
- [ProgressView](/docs/components/progressview): Display measurable progress or an indeterminate task.
- [RadialGradient](/docs/components/radialgradient): RadialGradient fills a view outward from a center point using color stops.
- [Redacted](/docs/components/redacted): Redacted adapts SwiftUI's `redacted` modifier into an explicit placeholder or privacy wrapper on the web.
- [Refreshable](/docs/components/refreshable): Refreshable adapts SwiftUI's `.refreshable` modifier into an explicit web container with a refresh affordance and busy state.
- [SafeArea](/docs/components/safearea): Inset content using browser safe-area environment variables.
- [SafeAreaInset](/docs/components/safeareainset): SafeAreaInset adapts SwiftUI's `.safeAreaInset` modifier into an explicit layout container for the web.
- [ScenePadding](/docs/components/scenepadding): ScenePadding adapts SwiftUI's `scenePadding` modifier into an explicit layout wrapper for web scenes and grouped screens.
- [ScrollBounceBehavior](/docs/components/scrollbouncebehavior): ScrollBounceBehavior adapts SwiftUI's `scrollBounceBehavior` modifier into an explicit wrapper.
- [ScrollClipDisabled](/docs/components/scrollclipdisabled): ScrollClipDisabled adapts SwiftUI's `scrollClipDisabled` modifier into an explicit wrapper.
- [ScrollIndicators](/docs/components/scrollindicators): ScrollIndicators adapts SwiftUI's `scrollIndicators` modifier into an explicit wrapper.
- [ScrollTarget](/docs/components/scrolltarget): ScrollTarget marks a stable scroll destination that can be resolved by `ScrollViewReader`.
- [ScrollTransition](/docs/components/scrolltransition): ScrollTransition adapts SwiftUI's `scrollTransition` modifier into an explicit wrapper for web layouts.
- [ScrollView](/docs/components/scrollview): Scroll content vertically or horizontally inside a bounded container.
- [ScrollViewReader](/docs/components/scrollviewreader): ScrollViewReader exposes a proxy that can scroll to child `ScrollTarget` anchors by identifier.
- [SearchField](/docs/components/searchfield): SearchField provides a dedicated search input with a value-first callback, aligned with SwiftUI's searchable input patterns while remaining an explicit web control.
- [Section](/docs/components/section): Group related rows under an optional header.
- [SecureField](/docs/components/securefield): Enter a password through a native, visually masked input.
- [SettingsLink](/docs/components/settingslink): SettingsLink mirrors SwiftUI's settings-entry affordance while staying web-native as a standard link.
- [Capsule](/docs/components/shape/capsule): Capsule renders a pill-shaped surface with fully rounded ends, aligned with SwiftUI's `Capsule` mental model.
- [Circle](/docs/components/shape/circle): Draw a circular shape.
- [Ellipse](/docs/components/shape/ellipse): Ellipse renders an oval surface inside the supplied frame, aligned with SwiftUI's `Ellipse`.
- [Rectangle](/docs/components/shape/rectangle): Draw a rectangular shape with square corners.
- [RoundedRectangle](/docs/components/shape/roundedrectangle): Draw a rectangle with rounded corners.
- [UnevenRoundedRectangle](/docs/components/shape/unevenroundedrectangle): UnevenRoundedRectangle extends the rounded rectangle shape by letting each corner radius vary independently.
- [ShareLink](/docs/components/sharelink): ShareLink presents a platform share action. On the web it uses the Web Share API when available and falls back to opening shareable URLs.
- [Sheet](/docs/components/sheet): A modal presentation with a focus trap, background isolation and scroll lock. Set `isPresented` and close it from `onDismiss`.
- [Slider](/docs/components/slider): Select a numeric value with a native range input.
- [Spacer](/docs/components/spacer): Distribute unused space along a stack’s main axis.
- [Stepper](/docs/components/stepper): Adjust a number with increment and decrement buttons.
- [SwipeActions](/docs/components/swipeactions): SwipeActions adapts SwiftUI's swipe-revealed row actions into an explicit, accessible web row wrapper. On the web, actions are revealed with a toggle instead of relying on touch-only gestures.
- [SymbolEffect](/docs/components/symboleffect): SymbolEffect adapts SwiftUI's symbol animation modifiers into an explicit wrapper component for the web.
- [Table](/docs/components/table): Table renders structured tabular data with explicit `TableColumn` definitions, aligned with SwiftUI's table mental model.
- [TableColumn](/docs/components/tablecolumn): TableColumn defines a single column inside `Table`, including its header title and row value renderer.
- [TabView](/docs/components/tabview): Switch between named content panels.
- [Text](/docs/components/text): Display inline text with optional line truncation.
- [TextEditor](/docs/components/texteditor): Edit multiline text in a native textarea.
- [TextField](/docs/components/textfield): Edit a single line of text using a native input.
- [TextSelection](/docs/components/textselection): TextSelection adapts SwiftUI's `textSelection(_:)` modifier into an explicit wrapper that controls browser text selection semantics.
- [TimelineView](/docs/components/timelineview): TimelineView re-renders its content on a fixed cadence, matching SwiftUI's scheduled-update mental model with a simple interval-based web adaptation.
- [Toggle](/docs/components/toggle): Turn a boolean setting on or off.
- [Toolbar](/docs/components/toolbar): Arrange actions in a horizontal toolbar.
- [UIProvider](/docs/components/uiprovider): Configure theme, accent color, design tokens and glass for a React subtree.
- [Unredacted](/docs/components/unredacted): Unredacted adapts SwiftUI's `unredacted` modifier into an explicit wrapper that opts nested content out of placeholder styling.
- [VideoPlayer](/docs/components/videoplayer): VideoPlayer wraps the native browser video element while keeping SwiftUI's dedicated media-player mental model.
- [ViewThatFits](/docs/components/viewthatfits): ViewThatFits picks the first layout variant that fits the available width. The web version uses `data-min-width` hints on child views to choose an appropriate variant.
- [VisualEffect](/docs/components/visualeffect): VisualEffect adapts SwiftUI's visual-effect modifiers into an explicit surface wrapper for the web.
- [VSplitView](/docs/components/vsplitview): VSplitView stacks multiple panes vertically while preserving the SwiftUI split-view mental model in a web-native layout container.
- [VStack](/docs/components/vstack): Arrange children vertically with configurable spacing and horizontal alignment.
- [ZStack](/docs/components/zstack): Layer children in the same grid area.
