---
title: "MatchedGeometryEffect"
description: "MatchedGeometryEffect adapts SwiftUI's `matchedGeometryEffect` modifier into explicit shared metadata on the web."
---

**Status**: adapted

## Usage and limitations

- Annotates source/target elements with geometry metadata and light CSS styling. It does not measure or animate shared geometry. For browser shared-element navigation, use `NavigationLink` with `view-transition`.
