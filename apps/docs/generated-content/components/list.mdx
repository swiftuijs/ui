## Usage and limitations

- Accepts React children; use consistent row padding, Divider for separation, and Section for named groups.
- Place long lists in a bounded ScrollView or page scroll area. This component mounts all rows; use a lazy layout or pagination for large datasets.
- Row controls need their own labels and keyboard behavior.
