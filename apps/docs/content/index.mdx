## Read the limits first

SwiftUI.js uses browser rendering. It does not reproduce every native SwiftUI API or Apple system behavior. Read a component's usage notes before adopting it; experimental exports may change.

Status terms: **aligned** follows SwiftUI intent closely; **adapted** uses browser-specific behavior; **partial** has documented gaps; **planned** is not shipped behavior. These describe scope, not a guarantee of production acceptance. Validate the components you use in your target browsers.
