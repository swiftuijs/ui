# Button

A native HTML button with SwiftUI-inspired styling. Pass ordinary button props and an `onClick` handler; use `type="submit"` inside a form.

## Usage and limitations

- Defaults to `type="button"` so clicking does not submit a form accidentally.
- Supports native keyboard activation, `disabled`, `aria-*`, `className`, and `style`.
- Use a visible action label, or `aria-label` for an icon-only button.
- Choose `buttonStyle="plain"`, `"bordered"`, or `"borderedProminent"`; the default `"automatic"` uses the plain appearance. Use `buttonRole="destructive"` for a destructive action.
