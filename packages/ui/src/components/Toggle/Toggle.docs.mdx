# Toggle

Turn a boolean setting on or off.

## Basic Usage

<Canvas of={ToggleStories.Default} />

## Usage and limitations

- Provide `isOn` and boolean `onChange`; state is controlled by the parent. `disabled` blocks interaction.
- Use a clear visible label or `aria-label` naming the setting. Native keyboard activation and on/off feedback are provided.
- Group related settings and keep their state in React.
