## Usage and limitations

- Control visibility with `isVisible` and close from `onDismiss`.
- Buttons support `default`, `cancel`, and `destructive` styles. Use descriptive labels and mark dangerous actions as destructive.
- The shared modal traps focus, isolates the background and restores focus on closing. Check keyboard dismissal and labeling in your composition.
