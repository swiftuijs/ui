## Usage and limitations

- `edges` defaults to all four edges; choose individual edges when only part of the screen needs an inset.
- For notched mobile browsers, add `viewport-fit=cover` to the viewport meta tag. Insets depend on browser/device support; native Apple system layout is not emulated.
- Usually apply at an application boundary. Check important content on actual notched devices and avoid duplicated insets.
