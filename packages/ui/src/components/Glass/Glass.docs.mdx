## Usage and limitations

- Inherits `UIProvider` preferences; `glass` overrides them for this surface. Glass is off by default.
- `glass={{ enabled: true, intensity: 0.6, variant: 'regular' }}` enables it. Intensity is clamped to 0–1; `regular` softens the background for legibility, while `clear` transmits more color and uses less blur. `false` or zero intensity uses an opaque fallback.
- Use on controls over content. Keep forms and content cards opaque and check contrast over your actual background.
- Chromium adds shape-aware SVG edge refraction after hydration. Foreground content remains unfiltered and interactive. Safari and Firefox use CSS blur, tint and highlights; set `renderer: 'css'` to use that path everywhere.
- SVG refraction needs `img-src data:` in a Content Security Policy; blocked images or an unavailable renderer keep the CSS fallback. Reduced transparency, increased contrast and forced colors use opaque surfaces; browsers without backdrop-filter also stay opaque.
- This web approximation does not reproduce Apple's system vibrancy or full native optical model. Maps are cached and rebuilt after size/radius changes settle; no cursor animation or graphics-engine dependency is added.
- See [theming and materials](/docs/concepts/theming/) for configuration and browser requirements.
