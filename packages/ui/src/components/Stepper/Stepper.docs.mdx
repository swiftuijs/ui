## Usage and limitations

- Controlled: `value`; uncontrolled: `defaultValue`. `onValueChange` and `onChange` receive the numeric update.
- `min`, `max`, and `step` constrain changes; buttons disable at the bounds. `disabled` disables the control.
- Keep both buttons visible and labeled; display the value in the surrounding form when needed.
