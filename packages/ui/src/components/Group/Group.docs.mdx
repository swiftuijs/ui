## Usage and limitations

- Renders a `div`, so it can affect flex/grid layout and inherited styles. It is not a React Fragment or a layout-transparent native SwiftUI Group.
- Use `className` or `style` to apply shared styles; conditional rendering and nesting work as in React.
- Use a Fragment when you need no DOM wrapper.
