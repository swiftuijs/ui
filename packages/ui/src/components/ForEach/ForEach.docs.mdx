## Usage and limitations

- Provide `data`, `keyExtractor`, and `renderItem`. `renderItem` receives each item and its index.
- `keyExtractor` must return a unique, stable key; TypeScript infers item types from `data`.
- This is ordinary React array rendering: all items mount. It does not virtualize or provide a performance advantage over `.map()`.
- Use a lazy stack/grid for large scrolling datasets.
