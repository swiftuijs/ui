## Usage and limitations

- Wraps within available width; `lineLimit` truncates positive numbers of lines. Native CSS text styles and React children are supported.
- Renders a `span`, not a heading. Use semantic HTML headings for document hierarchy and avoid nesting block elements inside it.
- Ensure contrast and check long text on compact containers.
