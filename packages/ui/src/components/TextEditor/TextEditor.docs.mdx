## Usage and limitations

- Controlled: `value`; uncontrolled: `defaultValue`. Choose one mode and keep it consistent.
- `onChange` receives the native event; `onValueChange` receives the latest string.
- `rows` sets a fixed row count; otherwise explicit line breaks determine 3–8 rows. `placeholder`, `disabled`, and `readOnly` retain native behavior.
- Provide an associated HTML label or `aria-label`. Validate length/content at the form level; native keyboard and assistive-technology semantics are preserved.
