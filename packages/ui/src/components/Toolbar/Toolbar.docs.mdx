## Usage and limitations

- Provide `items` with `content` and optional `placement`; placement defaults to `automatic`.
- Placements are `navigation`, `cancellationAction`, `principal`, `automatic`, `confirmationAction`, and `destructiveAction`, rendered in that stable group order.
- Uses `role="toolbar"`; supply `aria-label` or `aria-labelledby` and accessible action labels.
- Use destructive placement for dangerous actions, keep actions consistent and reachable on mobile, and set a local `glass` override when needed.
