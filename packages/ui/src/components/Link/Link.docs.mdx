## Usage and limitations

- Provide a valid `destination` and descriptive link content. Native anchor attributes and React children are supported.
- For `target="_blank"`, use an appropriate `rel`, such as `noopener noreferrer`.
- Validate application-provided or user-generated URLs. Style with `style`/`className`; keep the destination understandable to keyboard and screen-reader users.
