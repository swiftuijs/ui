# ScrollTransition

ScrollTransition adapts SwiftUI's `scrollTransition` modifier into an explicit wrapper for web layouts.

## Usage and limitations

- Uses CSS effects driven by `phase` and `active` props. Scroll position is not observed automatically; update those props from application scroll logic.
