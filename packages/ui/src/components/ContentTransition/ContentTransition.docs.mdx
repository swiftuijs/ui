# ContentTransition

ContentTransition adapts SwiftUI's content-transition modifiers into brief feedback when its content changes.

## Usage and limitations

- Changed content fades in; `transition="scale"` also settles from 96% to its authored size. Rapid updates replace the previous feedback.
- `active={false}` and the system's Reduce Motion setting disable feedback. Browsers without Web Animations show the updated content immediately.
- `interpolate` falls back to opacity. Text/number interpolation and an outgoing-content crossfade are not implemented.
