# ContentTransition

ContentTransition adapts SwiftUI's content-transition modifiers into an explicit wrapper that annotates changing content on the web.

## Usage

<Canvas of={ContentTransitionStories.Opacity} />

## Variants

<Canvas of={ContentTransitionStories.Scale} />

## Usage and limitations

- Uses CSS classes and transitions for opacity, saturation or scale. It does not interpolate changing text/numbers or diff content like native SwiftUI; control `active` yourself.
