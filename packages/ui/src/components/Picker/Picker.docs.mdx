# Picker

Choose one value from a native select control.

## Usage and limitations

- Supply options with `value` and `label`. Controlled: `selection`/`onSelectionChange`; React aliases: `selectedValue`/`onValueChange`. Uncontrolled: `defaultSelection`.
- Callbacks return the original option value type. Option values must be unique after string coercion.
- The empty string is reserved for the hidden placeholder option and cannot be a real option value.
- Supports `disabled` and native keyboard/mobile behavior. Provide an accessible label and validate required selection in the form.
